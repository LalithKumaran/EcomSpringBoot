## 📌 Overview

This is a **Spring Boot REST API project** that demonstrates basic **CRUD operations** with **MySQL database integration**.

It is built for learning purposes to understand how Spring Boot works with REST APIs and database connectivity.

---

## ⚙️ Tech Stack

- ☕ Java 17  
- 🌱 Spring Boot  
- 🗄️ Spring Data JPA  
- 🐬 MySQL Database  
- 📦 Maven
